# Impossible Objects

Five live 3D scenes that run in the browser: a Thomas attractor, a Hopf fibration, liquid chrome, a black hole with gravitational lensing and a Mandelbulb.

Live: https://saksham.digital/impossible-objects/

Drag to orbit, scroll or pinch to zoom, click to disturb, keys 1 to 5 to switch scenes. One HTML file, three.js r128.
